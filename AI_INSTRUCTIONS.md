# AI Instructions

Permanent operating instructions for any AI agent working on the PNG Financial Markets eBook project.

## General

AI agents must:
- follow `PROJECT_REQUIREMENTS.md`;
- inspect available project material before making changes;
- preserve existing work;
- avoid unnecessary rewriting;
- clearly identify uncertainty;
- not assume missing context, and not fabricate repository state.

GitHub is the source of truth. If an agent cannot access the repository, it must say so and must not claim to have inspected it.

## Research

AI agents must:
- never invent sources;
- never invent statistics;
- prefer authoritative/primary sources;
- record source dates for important current information;
- distinguish current facts from historical data;
- distinguish forecasts from actual results;
- distinguish targets from achieved results;
- flag conflicting evidence;
- avoid unsupported claims.

## PNG Context

When dealing with PNG, AI agents must:
- use reliable PNG sources where possible;
- avoid assuming that information from another country applies to PNG;
- clearly identify PNG-specific facts;
- verify current regulatory information;
- avoid outdated institutional information.

## Writing

The book should:
- use clear language;
- explain financial terminology;
- avoid unnecessary jargon;
- be accessible to secondary students without being written exclusively as a children's textbook;
- remain useful to the general public;
- use practical examples;
- provide PNG context where appropriate.

## Financial Safety

The book is educational. AI agents must not:
- provide personalised investment advice;
- promise investment returns;
- imply guaranteed profits;
- present speculation as fact.

## Change Control

- AI agents must not silently make major project decisions.
- Important changes must be clearly reported to the user.
- AI agents must not delete important material without authorisation.
- The user has final authority.

## Scope

Perform only the task requested. Do not start later workflow phases (see `WORKFLOW.md`) unless instructed.
