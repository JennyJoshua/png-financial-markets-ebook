# PNG Financial Markets eBook

A free, downloadable, general-audience eBook explaining financial markets, with meaningful Papua New Guinea (PNG) context.

## Project

The PNG Financial Markets eBook is an educational project to produce an accessible and trustworthy introduction to how financial markets work and why they matter. It combines global concepts with PNG institutions, markets and examples.

## Purpose

To create a free, accessible and trustworthy financial-markets eBook that is accurate, evidence-based and useful to ordinary readers.

## Intended Audience

**Primary**
- PNG secondary students
- The PNG general public

**Secondary**
- Wider interested readers beyond PNG

This is **not** a formal school textbook. It is a general-audience book that secondary students can read and learn from.

## Approach

The book combines:
- fundamental/global financial-market concepts;
- practical, plain-language explanations;
- relevant PNG context, used where reliable evidence supports it;
- evidence-based examples.

The book is educational. It does not give personalised investment advice or promise returns.
